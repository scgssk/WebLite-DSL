# Contributing to WebLite

Thank you for your interest in contributing to **WebLite**! 🎉

## How to Contribute

1. **Fork the repository**

2. **Clone your fork**

   ```bash
   git clone https://github.com/your-username/WebLite-DSL.git
   cd WebLite-DSL
   ```

3. **Create a new branch**

   ```bash
   git checkout -b my-feature
   ```

4. **Make changes and commit**

   ```bash
   git add .
   git commit -m "Add feature XYZ"
   ```

5. **Push to your fork**

   ```bash
   git push origin my-feature
   ```

6. **Open a Pull Request** from your fork to the `main` branch

---

## Code Style

* Follow **PEP8** guidelines for Python
* Keep the code clean, modular, and well-documented
* Use clear and descriptive commit messages

---

## Need Help?

Feel free to open an [Issue](https://github.com/scgssk/WebLite-DSL/issues) if you’re stuck or have questions.
